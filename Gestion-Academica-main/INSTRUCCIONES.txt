NOTAS + FILTRAR ESTUDIANTES + RENDIMIENTO
=========================================

Ya esta escrito dentro del proyecto (sin botones, esos los pones tu):
  - src/formulariosinternos/IFrmNotas.java
  - src/formulariosinternos/IFrmFiltrarEstudiantes.java
  - src/formulariosinternos/IFrmRendimiento.java
  - src/gestionacademica/FrmPrincipal.java   (guarda cargo/idProfesor y se los pasa a IFrmNotas)
  - src/formulariosinternos/IFrmMatricula.java      (arreglo: "== 0" ahora es "== -1")
  - src/formulariosinternos/IFrmNuevoProfesor.java  (arreglo: "== 0" ahora es "== -1")
  - GestionAcademica.sql  (se agrego sp_combo_asignaturas_profesor)

PASO 1 - Base de datos (MySQL Workbench)
  Ejecuta SOLO sql/solo_procedimiento_nuevo_SIN_BORRAR_DATOS.sql
  (GestionAcademica.sql completo empieza con DROP DATABASE y borra los datos;
   usalo solo si quieres la base desde cero).

PASO 2 - Arrastrar componentes (vista Design; clic derecho > Change Variable Name)
  Hasta que lo hagas las tres clases marcan errores rojos. Es normal.
  Al terminar, estira la ventana (esquinas) para que quepa todo.

  IFrmNotas
    - Label "Asignatura"          + ComboBox   -> cbmAsignatura
    - Label "Periodo"             + ComboBox   -> cbmPeriodo
    - Button "Cargar estudiantes"              -> btnCargar
    - Table                                    -> tableNotas
    - Label "Nota (0 a 5)"        + Text Field -> txtNota
    - Button "Guardar nota"                    -> btnGuardar

  IFrmFiltrarEstudiantes
    - Label "Grado"               + ComboBox   -> cbmGrado
    - Label "Asignatura"          + ComboBox   -> cbmAsignatura
    - Button "Filtrar"                         -> btnFiltrar
    - Table                                    -> tableEstudiantes

  IFrmRendimiento
    - Label "Nota minima para aprobar" + Text Field -> txtNotaMinima
    - Label "Grado"               + ComboBox   -> cbmGrado
    - Label "Asignatura"          + ComboBox   -> cbmAsignatura
    - Label "Estudiante"          + ComboBox   -> cbmEstudiante
    - Label "Periodo"             + ComboBox   -> cbmPeriodo
    - Button "Mostrar informe"                 -> btnMostrar
    - Table                                    -> tableRendimiento

PASO 3 - Conectar los botones (doble clic en cada uno, una sola linea)
    IFrmNotas:               btnCargar   ->  cargarEstudiantes();
                             btnGuardar  ->  guardarNota();
    IFrmFiltrarEstudiantes:  btnFiltrar  ->  filtrarEstudiantes();
    IFrmRendimiento:         btnMostrar  ->  mostrarRendimiento();

NOTAS
  - En los combos de Grado, Asignatura, Estudiante y Periodo, dejar
    "Seleccione..." significa "todos" (no filtra por ese campo).
  - Los decimales van con punto: 3.5 (con coma sale el mensaje de error).
  - El rendimiento solo muestra estudiantes que ya tienen notas.
  - Estado REPROBADO = promedio/nota por debajo de la nota minima = bajo rendimiento.
  - sp_combo_asignaturas no se toco (lo usan IFrmNuevoProfesor, Filtrar y
    Rendimiento). El profesor, en Notas, usa sp_combo_asignaturas_profesor.
  - Se quito la carpeta build/ (tenia clases viejas vacias); NetBeans la
    vuelve a crear sola al ejecutar el proyecto.
